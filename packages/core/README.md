# `@neopolitan/core`

Pure TypeScript + Zod core contracts for [Neopolitan](https://github.com/milesangelo/neopolitan): `ProviderDriver`, `ProviderAdapter`, `AgentSession`, `ProviderCapabilities`, canonical `AgentEvent` union, `GateMiddleware`, failure sanitization (`redactSecrets` / `classifyProviderFailure`), `EventHub`, and `ExecutionRuntime`.

```bash
npm install @neopolitan/core zod
```
