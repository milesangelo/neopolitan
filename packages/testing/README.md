# `@neopolitan-ai/testing`

Testing utilities for [Neopolitan](https://github.com/milesangelo/neopolitan): Vitest-free `MockExecutionRuntime` + `createMockDriver` at root, and `runProviderConformanceSuite` under `@neopolitan-ai/testing/conformance`.

```bash
npm install -D @neopolitan-ai/testing
```
