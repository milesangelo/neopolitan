# `@neopolitan-ai/adapter-acp`

Hardened Agent Client Protocol (ACP v1/v2) adapter over `@agentclientprotocol/sdk` with built-in dialect flavors (`opencode`, `antigravity`, `grok`, `kiro`, `copilot`, `omp`, `pi`) and fail-closed workspace path policy.

```bash
npm install @neopolitan-ai/adapter-acp
```
