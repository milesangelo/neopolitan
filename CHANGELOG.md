# Changelog

All notable changes to `neopolitan-ai` and `@neopolitan-ai/*` are documented in this file and managed by [Changesets](https://github.com/changesets/changesets).

## 0.1.0

### Highlights
- Initial release of all 12 scoped `@neopolitan-ai/*` packages (`core`, `runtime-local`, `testing`, `adapter-acp`, `adapter-claude`, `adapter-codex`, `adapter-pty`, `auth`, `sessions`, `workspace`, `server`, `orchestration`) plus the `neopolitan` umbrella package and zero-dependency CLI (`doctor`, `run`, `serve`, `handoff`).
- Shared `@neopolitan-ai/testing/conformance` suite, golden wire-transcript fixtures (`tests/fixtures/`), `publint` + `attw` ESM packaging checks, cross-OS GitHub Actions matrix, VitePress + TypeDoc docs site, and `llms.txt` / `AGENTS.md`.
